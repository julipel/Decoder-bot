# ПРОМТ-СБОРЩИК: система контента из 3 файлов (ИНСТРУКЦИЯ / СТИЛЬ / СТРУКТУРА)

**Что это.** Один промт. Кидаешь его в любую ИИ вместе с примером канала-конкурента (или своим текстом) и названием ниши. На выходе ИИ собирает 3 файла под твою нишу: ИНСТРУКЦИЯ, СТИЛЬ, СТРУКТУРА. Эти 3 файла потом прикрепляешь к любой ИИ, даёшь тему, и она пишет сильную статью в голосе канала. Работает для ЛЮБОЙ ниши. Заточено под Дзен.

**Как пользоваться (1 шаг):** вставь всё ниже, заполни блок ВХОД, вставь тексты примеров. Получишь 3 файла.

---

- **ОБЪЁМ (опц.):** короткие ~3–5к / средние 5–10к / лонги 10–20к символов.

## РОЛЬ
Ты методолог контента и редактор. По примеру канала ты реконструируешь, что делает его сильным, и собираешь воспроизводимую систему из 3 файлов, которая позволяет ЛЮБОЙ ИИ писать статьи такого же уровня в этой нише, не копируя чужой текст.

## ПРИНЦИП РАБОТЫ С ПРИМЕРОМ
Извлекай ПРИНЦИПЫ и ЧИСЛА, а не фразы. Бери сильные приёмы конкурента, усиливай их, обходи его слабые места и ИИ-клише. Никогда не копируй предложения дословно, это выдаёт вторичность. Цель: тот же уровень, свой голос.

## ЗАДАЧА, в 3 прохода

**Проход 1. Тип ниши.** Определи тип по примеру и назови его одной строкой. Четыре типа:
- **narrative** (истории, проза, драмы): цель, эмоция и удержание сюжетом.
- **instructional** (гайды, рецепты, DIY, инструкции): цель, читатель получает результат.
- **factual** (новости, факты, обзоры, наука-поп): цель, точность и польза.
- **analytical** (разборы, мнения, аналитика): цель, авторская позиция и глубина.

Смешанная ниша: выбери ведущий тип, второй отметь как вторичный.

**Проход 2. Анализ голоса (числа из примера).** Извлеки ТОЛЬКО из текста:
- ритм: доли коротких (1–6 слов) / средних (7–10) / длинных (11+), в %
- средняя длина предложения (слов); абзац: средние символы, доля абзацев в 1–2 предложения
- начала предложений: % с «я», % с союзов (И, Но, А), % прочее
- доля диалогов, %; пунктуация: точки / восклицания / вопросы, %
- тон, обращение (ты или вы), сложность
- нишевый словарь: термины и фразы, звучащие экспертно
- личные маркеры автора: обороты, делающие голос узнаваемым
- клише и ИИ-штампы, которых в этой нише надо избегать

**Проход 3. Сборка 3 файлов** по шаблонам ниже. В КАЖДЫЙ файл встрой ПРАВИЛА ДЗЕНА. Каждый файл около 2 страниц: ключевое, с числами и 2–3 примерами, без воды.

---

## ПРАВИЛА ДЗЕНА (встраивать в каждый файл)
- **Тире:** длинное `—` запрещено. Среднее `–` редко (макс 3–5 на статью, диалоги и диапазоны). Вместо тире: запятая, точка, союз, двоеточие. Дефис только в составных словах (красно-синий).
- **Кавычки:** только «ёлочки».
- **Абзацы:** сплошной поток, без пустых строк между абзацами (пустая только вокруг разделителя `***`).
- **Ритм живой:** не 3+ коротких подряд, не 2+ длинных подряд; союзы в начале 20–30% предложений.
- **Антишлак:** убирать ИИ-маркеры (однако→но, затем→потом, является→это, данный→этот, осуществлять→делать, стоит отметить→убрать, в современном мире→убрать).
- Не использовать конструкцию «Число. Число + контекст»; одно число не повторять 3+ раз.
- **Явность:** важный факт сказать ПРЯМО словами, не намёком (ЦА читает быстро, не перечитывает).
- **[только narrative] Монетизация:** событие → реакция героя, БЕЗ детальных описаний травм, смерти, насилия, медицины; романтика без телесных ощущений, в публичных местах.

## ШАБЛОН ФАЙЛА 3 — СТРУКТУРА (адаптивная по типу)
```
# СТРУКТУРА — [НИША] (Дзен)
Тип ниши: [type].

## Каркас статьи (по типу)
narrative: Крючок → Завязка → Развитие (2–4 сцены + микрокрючки) → Поворот → Финал-резонанс. Опц.: ружьё (заряд → напоминание → выстрел).
instructional: Проблема или результат → Что понадобится → Шаги (что, чем, сколько, как понять что готово) → Частые ошибки → Что дальше.
factual: Зацепка (факт или противоречие) → Тезис → Факты с атрибуцией «по данным...» → Вывод + рекомендация.
analytical: Парадокс или вопрос → Разбор → 2 перспективы → Авторская позиция (отделена от фактов) → Вывод для читателя.

## Форматы (2–3 под нишу)
Для каждого: когда использовать, блоки с бюджетом символов, ракурсы (варианты подачи, чтобы статьи не повторялись).

| № | Блок | Содержание | Символов |
|---|---|---|---|

## Крючок (по типу)
narrative: ситуация из жизни / момент выбора / сенсорная деталь.
instructional: проблема читателя / результат / типичная ошибка новичка.
factual: неожиданный факт / свежая новость / противоречие мнению.
analytical: парадокс / неочевидная связь / вопрос без простого ответа.

## Финал и удержание (по типу)
narrative: эмоциональный резонанс, читатель ЧУВСТВУЕТ.
instructional: итог + вариации + что дальше.
factual: конкретный вывод + практическая рекомендация.
analytical: авторская позиция + вывод для жизни читателя.

## Микрокрючки
Каждые ~1500–2000 символов: вопрос, недосказанность, неожиданная деталь.

[если factual или analytical] ## Источники и факт-чек
Каждый факт: источник + год. Мнение отделять от факта. Числа макс 2–3 упоминания.
```
